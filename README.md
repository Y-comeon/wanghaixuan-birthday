# 绚丽动态生日祝福

这是一个无需构建工具的静态网页。手机浏览器或微信扫描二维码后即可播放动画。

## 本地预览

在此目录运行：

```powershell
py -m http.server 8080
```

电脑打开 `http://localhost:8080`。如果手机和电脑连接同一个 Wi‑Fi，可用电脑局域网 IP 访问，例如 `http://192.168.1.10:8080`。

## 生成二维码

先安装二维码依赖：

```powershell
py -m pip install qrcode[pil]
```

将正式公网网址作为参数运行：

```powershell
py generate_qr.py https://你的用户名.github.io/仓库名/
```

脚本会生成 `birthday-qr.png` 和 `birthday-qr.svg`。当前目录中的二维码需要替换为你的实际发布地址后再使用。

## 发布到 GitHub Pages

1. 在 GitHub 新建一个仓库。
2. 上传本目录中的 `index.html`、`style.css`、`app.js` 和 `README.md`。
3. 在仓库的 **Settings → Pages** 中选择 `Deploy from a branch`。
4. 选择默认分支的根目录并保存。
5. 等待 GitHub Pages 给出网址。
6. 使用该网址重新运行 `generate_qr.py`，然后把生成的二维码保存或打印。

## 交互说明

- 页面首次打开会播放一次完整入场动画。
- 开场从侧俯视逐步转到平视，由粒子逐层描绘蛋糕线稿，再依次沿矢量笔画写出加粗数字“21”、连笔英文祝福，最后逐字淡入楷体姓名。
- 入场结束后，蛋糕、数字、文字、星尘和烟花保持连续动态。
- 点击页面或右下角“重新播放”按钮可再次播放入场动画。
- 英文祝福以连笔矢量笔画书写；“王海璇”以楷体按从左到右的顺序逐字淡入，显示后保持可见。
- 蛋糕以三层粒子线稿呈现，包含奶油滴边、糖珠、装饰纹理、托盘、条纹蜡烛和动态内外焰。
- 开场后会有多颗较慢的随机七彩流星以不同时间间隔从左上向右下穿过整个页面，并留下同色渐散尾流。
- 多条祝福语会错峰淡入并可同时显示，在上方或蛋糕两侧的安全区域随机定位，文字之间会避让。
- 蛋糕尺寸同时适配屏幕宽度和高度；“21”笔迹加粗并与转场期间蛋糕及蜡烛最高位置保持至少 24px 间距，开场时背景粒子会避开数字书写区域。
- 页面底部提示为“轻触屏幕，祝福+1”。
- 不包含音频，适合微信内置浏览器直接打开。

## 布局与姓名验证

- 可在浏览器开发者工具中分别模拟桌面宽屏、手机竖屏和较矮横屏，重播开场并检查数字“21”与蛋糕、蜡烛的间距。
- 姓名使用 `STKaiti`、`KaiTi` 或系统楷体字体，缺失时回退到衬线字体。
- `index.html` 使用带版本参数的 `app.js?v=6`，更新脚本后可递增参数以刷新浏览器缓存。
