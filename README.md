# 绚丽动态生日祝福

这是一个无需构建工具的静态网页。手机浏览器或微信扫描二维码后即可播放动画。

## 本地预览

在此目录运行：

```powershell
py -m http.server 8080
```

电脑打开 `http://127.0.0.1:8080/`。手机与电脑处在可互访的同一局域网时，可直接在手机浏览器中打开电脑的局域网地址，例如 `http://192.168.1.10:8080/`。公网访问使用 GitHub Pages 发布后的 HTTPS 链接。

## 生成二维码

先安装二维码依赖：

```powershell
py -m pip install qrcode[pil]
```

将正式公网网址作为参数运行：

```powershell
py generate_qr.py https://你的用户名.github.io/仓库名/
```

脚本会生成 `birthday-qr.png` 和 `birthday-qr.svg`。当前目录中的二维码需要替换为你的实际发布地址后再使用。

## 发布到 GitHub Pages

1. 在 GitHub 新建一个仓库。
2. 上传 `index.html`、`style.css`、`app.js`、`cake.js`、`gentleman2.mp3`、`name-zcool-kuaile.woff2`、`invitation-kuaile.woff2`、`name-font-OFL.txt` 和 `README.md`。
3. 在仓库的 **Settings → Pages** 中选择 `Deploy from a branch`。
4. 选择默认分支的根目录并保存。
5. 等待 GitHub Pages 给出网址。
6. 使用该网址重新运行 `generate_qr.py`，然后把生成的二维码保存或打印。

## 交互说明

- 页面打开后先显示动态生日信封。点击“点击查收”后，封盖掀开、信纸升起，镜头穿过信纸中的星光，三颗主光粒接入蛋糕轨迹。默认转场约 3.1 秒。
- 蛋糕聚合约需 8 秒。开场镜头从侧上方靠近蛋糕，蓝紫光轨带着粒子螺旋上升。托盘和每层蛋糕成形时释放扩散光环和带短尾的星屑。蜡烛亮起后，接着写出“21”和连笔英文祝福。
- 蛋糕成形后，镜头持续环绕并交替抬高和降低。系统开启“减少动态效果”时，镜头移动幅度和速度会降低。帧率持续偏低时，网页会自动降低粒子密度和渲染分辨率。
- 蛋糕成形后，红、橙、蓝三颗光粒沿不同倾角绕过蛋糕各层，从上方俯视时统一为顺时针。每次查收都会重新随机分配颜色、轨道倾斜方向和速度。
- 开始构建蛋糕约 18.5 秒后第一次切片，之后每 20 秒循环。底层的一小块蛋糕以粒子形式移到右侧，转动展示切面夹层、奶油和糖珠。切片先上下拉伸回弹，再左右拉伸回弹，周围有五颗摇曳的实心红色粒子爱心。展示后切片逐粒归位。
- 蛋糕开始构建时显示右下角的“重新播放”按钮，点击后返回信封，可再次查收。蛋糕场景中轻触画面会放飞一颗逐渐消散的随机彩色粒子爱心。
- 页面打开时会尝试循环播放同目录中的 `gentleman2.mp3`。左上角播放按钮可以暂停或恢复，竖向音量滑块位于按钮下方并显示当前百分比。手机上可上下拖动滑块调节。若浏览器限制自动播放，需点播放按钮启动音乐。点击动画画面不会启动或恢复音乐。
- “王海璇”从左到右逐字凝聚成冰蓝至淡紫色的粒子艺术字。
- 蛋糕的顶面、侧壁、奶油滴边、糖珠、托盘和条纹蜡烛均由粒子组成。
- 三层分别插着 9、7、5 根蜡烛。每次开场或重播，每根蜡烛都会独立从七色中随机选色。
- 数字“2”和“1”每次开场或重播会共同抽取同一个七彩色，因此两位数字颜色始终一致。
- 信封待机和蛋糕开场结束后，随机七彩流星会陆续从左上向右下掠过，并留下渐散尾流。信封周围还有多层彩色光弧和闪烁星尘。
- 多条祝福语会错峰淡入并可同时显示，在上方或蛋糕两侧的安全区域随机定位，文字之间会避让。
- 蛋糕尺寸同时适配屏幕宽度和高度。开场时背景粒子会避开“21”的书写区域。
- 页面底部提示为“轻触屏幕，祝福+1”。
- 连续播放一段时间后会进入短暂庆祝模式，中心光晕、彩色烟花和环形光幕会同步增强，Happy Birthday 使用之前的简洁排版。
- 点击“王海璇”姓名时，名字会散开成彩色粒子并聚合成彩色爱心，持续 3 秒。动画期间再次点击姓名会延长 1 秒。
- 蛋糕两次拉扯开始时各触发一次切片外围汁水爆发，粒子从右侧展示中的切出蛋糕块周围向四周放射，颜色随机为白色、蓝色或橙色。
- 累计点击动画画面 21 次会触发满屏漂浮爱心，并在“21”和蛋糕之间随机显示一句蓝白圣洁手写祝福：“愿你一直可爱，也一直被爱”、“愿你生活有惊喜，快乐有回音”或“愿你的每一天都闪闪发光”。
- 音频为 MP3 格式。发布到 GitHub Pages 时请一并上传 `gentleman2.mp3`。

## 布局与姓名验证

- 可在浏览器开发者工具中分别模拟桌面宽屏、手机竖屏和较矮横屏，重播开场并检查数字“21”与蛋糕、蜡烛的间距。
- 姓名的粒子轮廓取自本地提供的站酷快乐体三字字体子集，各字略微错落。授权见 `name-font-OFL.txt`。
- “点击查收”使用独立的站酷快乐体四字子集，授权见 `name-font-OFL.txt`。
- 当前入口脚本版本为 `v=36`，蛋糕脚本版本为 `v=19`，样式版本为 `v=17`。更新网页资源时可递增对应参数以刷新缓存。
